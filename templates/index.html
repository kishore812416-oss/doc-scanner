What Security Checks Are Performed?

1. Root User Execution

Inspects Config.User to flag containers running as UID 0 (root). Running processes as root increases vulnerability blast radius during container escapes.

2. Exposed & Risky Ports

Analyzes Config.ExposedPorts to identify risky administrative or database endpoints (e.g., SSH 22, Telnet 23, MongoDB 27017, Redis 6379) exposed to public networks.

3. Base Image & Tag Policy

Evaluates image release tags. Warns against non-deterministic tags like :latest or :dev that break build reproducibility and introduce unvetted updates.

4. Hardcoded Secrets Scan

Scans environment variables (Config.Env) and layer command history for sensitive keyword patterns like passwords, API keys, tokens, and AWS credentials.
